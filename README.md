# Halo One
Halo One is a very compact and lightweight DIY PCVR headset, that features:
- Dual 1600x1600 90hz LCD panels,
- 6DoF using PS3 Move cameras,
- Fresnel Lenses,
- Compatibility with SteamVR,
- Based on Raspberry Pi Pico 2 microcontroller and LSM6DS3 IMU board,
- Comfortable halo strap.

## Bill Of Materials
- 1x RPI Pico 2,
- 1x LSM6DS3 board,
- 2x Fresnel Lens, d40mm, fl28mm,
- 2x 1600x1600 90hz display,
- 1x Display Driver Board,
- x25 M2, 6mm long self tapping screws,
- All 3D printed parts,
- Double sided tape,
- Quest 2 stock head strap, without top part.
